# Weather Icons

Icon Structure & Meaning:

- Characters 1-2: Represent the weather condition (e.g., 01 = clear, 10 = rain, 13 = snow).
- Character 3: Indicates day (d) or night (n).

Common Icon Codes:

```
01d/01n: Clear sky (Sunny/Clear Night)
02d/02n: Few clouds
03d/03n: Scattered clouds
04d/04n: Broken clouds / Overcast
09d/09n: Shower rain
10d/10n: Rain
11d/11n: Thunderstorm
13d/13n: Snow
50d/50n: Mist/Fog
```
